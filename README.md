# Solution Management — student page

This folder is the source of one page on the live course site:
**https://monosoft.online/emas/solutionmanagement**

It is the only public part of the project. The rest of the course application is
private.

## How to change the page

1. Open `index.html` here in your browser.
2. Edit it (GitHub lets you edit a file straight from the web page — no software
   to install).
3. Propose the change. That creates a pull request.
4. The lecturer reviews it. Once merged and deployed, your change is on the live
   page.

That review step is not a formality — it is the change-approval control you will
be auditing in this course.

## What you can and cannot do here

The page runs sandboxed: it cannot read data, cookies or storage belonging to the
rest of the course site. That is deliberate, and it is the difference between a
control that depends on someone being careful and a control that removes the risk
by design.

## Rules

- Keep it to this one file.
- No external scripts, fonts or images — the page must work on its own.
- Keep your section short.
